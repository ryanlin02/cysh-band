# 音樂廳場景開場校準工具

這是只在本機使用的視覺化工具，不會放進網站導覽，也不會自行發布。

1. 在 Finder 雙擊 `開啟場景校準工具.command`。
2. 瀏覽器會自動開啟；若沒有，開啟 `http://127.0.0.1:8092/`。
3. 逐一選擇場景，再選擇要當開場的照片。
4. 直接拖曳 360 度照片到希望訪客一打開就看到的畫面，按「設為此場景開場畫面」。
5. 全部設定完成後按「儲存所有設定到本機」。
6. 回到 Codex 說「發布場景校準設定」；在發布前仍可繼續調整。

工具會備份前一次設定到 `local/hall-tour-scene-calibrator/backup/`，並更新 `data/tour-entry-views.js` 與本機導覽產物。不要在工具開啟時手動編輯設定檔。
