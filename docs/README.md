# 維護文件分層

本目錄收納不需要放在網站根目錄、但仍需長期保存的維護文件。正式網站的程式與內容來源仍位於根目錄及 `content/`、`data/`、`scripts/`、`templates/` 等既有路徑。

## 目錄

- `ai/`：供 AI 開工時快速掌握現況與查找路徑的短版文件。
- `history/`：較早期的修改歷程；完整保留，但不應在一般任務中整份讀取。
- `archive/`：已過時或只供理解歷史背景的分析報告與快照。

## 使用原則

1. 一般網站修改先讀根目錄 `AGENTS.md` 與 `ai/網站目前狀態與AI讀取索引.md`。
2. 依任務搜尋正式規範或專題文件的相關段落，不預先讀完所有 Markdown。
3. `history/` 與 `archive/` 預設不讀；只有追查特定舊決策時，先用檔名、日期或關鍵字縮小範圍。
4. 實際程式、資料與檢查結果優先於本目錄中的文字紀錄。
